# Django Auth CRUD (To-Do App)

Aplicación web de gestión de tareas (to-do) con sistema de autenticación de usuarios, desarrollada con Django.

## Funcionalidades
- Registro e inicio de sesión de usuarios
- Crear, leer, actualizar y eliminar tareas (CRUD)
- Tareas asociadas a cada usuario autenticado

## Tecnologías
- Python
- Django
- SQlite

## Instalación local
​```bash
git clone https://github.com/ElmerMenjivar1999/django-auth-crud
cd django-auth-crud
pip install -r requirements.txt
python manage.py migrate
python manage.py runserver
​```
